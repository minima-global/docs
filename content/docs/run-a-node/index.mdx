## Desktop

Desktop users can launch Minima from a JNLP (Java Network Launch Protocol) file.

<Steps>

<Step>

<Heading as="h3">Install Open Web Start</Heading>

First, download and install [Open Web Start](https://openwebstart.com/download/).

</Step>

<Step>

<Heading as="h3">Download Minima</Heading>

Visit [this link](https://spartacusrex.com/jnlp.html), then click the ![Launch button](/img/runanode/jws-launch-button.png) to download Minima as a JNLPX file.

- Open / double-click the downloaded minima.jnlpx file to install Minima as an application. 

- A desktop shortcut will be created for you and you will be shown a security warning, select **Run**.

To ensure that Minima is always launched with Open Web Start, you may need to right-click > open with... and choose Open Web Start. If possible, choose "always".

</Step>

</Steps>

## CLI

At its core, Minima is a Java application. So on a server or CLI the easiest way to run Minima is to install Java and download the latest minima.jar.

<Callout title="Note" type="info">
  You can download the latest version of Minima from the [Minima GitHub releases
  page](https://github.com/minima-global/Minima/releases).

</Callout>

To run Minima, you need to have Java installed on your system. You can check if you have Java installed by running the following command in your terminal:

```bash title="Terminal"
java -version
```

<Callout title="Note" type="info">
  If you don't have Java installed, you can download it from the [Java
  website](https://www.java.com/en/download/).
</Callout>

<Steps>

<Step>

<Heading as="h3">Navigate to the directory where you saved the Minima jar</Heading>

```bash title="Terminal"
cd /path/to/your/minima/folder
```

</Step>

  <Step>
<Heading as="h3">Run Minima</Heading>

Adding `-mdsenable -mdspassword INSERTPASSWORD` will enable the minidapp system.

Adding `-p2pnodes megammr.minima.global:9001` will automatically connect you to the peer-to-peer network.

```bash title="Terminal"
    java -jar minima.jar -data .minima -p2pnodes megammr.minima.global:9001 -mdsenable -mdspassword INSERTPASSWORD
```

<Callout title="Connecting to the network" type="info">
Minima has no built-in list of peers, so a new node needs some connections to join the network. The command above adds them with `-p2pnodes`.

If you started Minima without it, add connections from the Minima terminal:

```
peers action:addpeers peerslist:megammr.minima.global:9001
```

You can also use a peers list URL, such as [https://spartacusrex.com/minimapeers.txt](https://spartacusrex.com/minimapeers.txt), or ask another node runner to share their connections.

</Callout>
  </Step>
</Steps>



## Docker

<Steps>

<Step>

<Heading as="h3">Start a new docker container</Heading>

There is also a nice docker image that you can use if you have Docker installed. Set a secure password below.

```bash title="Terminal"
docker run -d -e minima_mdspassword=INSERTYOURPASSWORD -e minima_desktop=true -v ~/minimadocker:/home/minima/data -p 9001-9003:9001-9003 --restart unless-stopped --name minima minimaglobal/minima:latest
```

</Step>

<Step>

<Heading as="h3">Log into your node</Heading>



Then you log into your node via https://127.0.0.1:9003/

Further guidance on starting a node in Docker desktop can be found [here](/docs/run-a-node/docker-desktop)

On a server (VPS), use `-e minima_server=true` instead of `-e minima_desktop=true`, so your node acts as a relay node. See [Linux VPS (Docker)](/docs/run-a-node/linux-vps-docker).

</Step>

</Steps>
